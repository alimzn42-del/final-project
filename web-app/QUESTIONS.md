# Checks that need the manager login

To do together with the owner (steps 14 to 16). The browser checks need the owner's own manager
login. Rows 4 to 6 do not: since step 16 they log in with the checks account (`CHECK_EMAIL` /
`CHECK_PASSWORD` in `.env`), never with a person's account.

Before them: start Docker Desktop, then `docker compose up -d --wait` (the images are built; after a
code change rebuild them one at a time, `pnpm stack:up` builds all at once and can run out of
memory on this laptop). The web app is at http://localhost:8080. The images were rebuilt on the
`web-app/` layout on 2026-11-03 (step 14, task 9) and checked without the login: `pnpm infra:check`
and `pnpm sim:check` pass, nginx serves the page, its scripts, deep links and the locale files, and
refuses the API without a login (401). The simulator image was rebuilt for step 15 on 2026-11-04.
